
# CareBridge Database Portfolio

## Project Overview

CareBridge is a simulated clinic database developed for the MIT 8103 Advanced Database Systems course at Miva Open University.

The project explores database design, SQL implementation, query processing and optimisation, transaction management, NoSQL data modelling, and distributed database concepts.

## Project Objectives

- Design a relational database for managing clinic patients, doctors, and appointments.
- Implement tables, relationships, primary keys, and foreign key constraints.
- Write and test SQL queries to retrieve related information.
- Explore query execution plans and database optimisation.
- Extend the case study to NoSQL and distributed database concepts as the portfolio progresses.

## Current Progress

The initial relational database has been created using MySQL. The Patients, Doctors, and Appointments tables have been implemented, sample records inserted, and a JOIN query tested to retrieve appointment information alongside patient and doctor details.

This portfolio will be updated as additional assessment activities are completed.
